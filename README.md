## ✨ Overview

ShopMaster is an all-in-one microservices framework tailored for building scalable and maintainable e-commerce applications. It offers a modular architecture with dedicated services for catalog, payment, shipping, orders, identity, notifications, promotions, and analytics, all designed to work cohesively. The core features include:

- 🧩 **Modular Design:** Seamlessly integrate multiple microservices, each with clear domain boundaries.
- 🚀 **API Excellence:** Built-in versioning, Swagger documentation, and environment-specific configs for robust API management.
- 🔒 **Security & Scalability:** JWT authentication, dependency injection, and environment-aware settings ensure secure, scalable deployments.
- 📦 **Data Management:** Repositories, DTOs, and object mappings streamline data flow and maintain consistency.
- 🧪 **Test-Driven Development:** Extensive source code summaries highlight a focus on reliable, maintainable code with comprehensive testing.

## 🚀 Getting Started

### 📋 Prerequisites

This project requires the following dependencies:

- **Programming Language:** CSharp
- **Package Manager:** Nuget, Npm

### ⚙️ Installation

Build ShopMaster from the source and install dependencies:

1. **Clone the repository:**

    ```sh
    ❯ git clone https://github.com/Bonandi22/ShopMaster
    ```

2. **Navigate to the project directory:**

    ```sh
    ❯ cd ShopMaster
    ```

3. **Install the dependencies:**

**Using [nuget](https://docs.microsoft.com/en-us/dotnet/csharp/):**

```sh
❯ dotnet restore
```
**Using [npm](https://www.npmjs.com/):**

```sh
❯ npm install
```

### 💻 Usage

Run the project with:

**Using [nuget](https://docs.microsoft.com/en-us/dotnet/csharp/):**

```sh
dotnet run
```
**Using [npm](https://www.npmjs.com/):**

```sh
npm start
```

### 🧪 Testing

Shopmaster uses the {__test_framework__} test framework. Run the test suite with:

**Using [nuget](https://docs.microsoft.com/en-us/dotnet/csharp/):**

```sh
dotnet test
```
**Using [npm](https://www.npmjs.com/):**

```sh
npm test
```
